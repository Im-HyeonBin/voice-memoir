목소리 발굴

개인정보 처리방침과 이용 안내

2026년 11월 26일부터 적용

이 서비스는

목소리 발굴은 흩어진 녹음에서 한 사람의 목소리를 찾아 해마다 모아 주는 무료 서비스예요. 개인 포트폴리오로 만들어 운영하고, 회원 가입 없이 써요. 운영자는 GitHub 사용자 Im-HyeonBin이고, 문의는 GitHub 저장소의 이슈로 받아요. 작동 방식과 소스 코드도 같은 저장소에 공개해 두었어요.

받는 정보와 지우는 때

정보쓰는 곳지우는 때
올린 녹음 파일과 파일 이름, 파일 시각목소리를 찾고 녹음 날짜를 어림하는 데마지막으로 쓰고 1시간이 지나면 지워요. 계속 쓰고 있어도 처음 올리고 3시간이 지나면 지워요. ‘올린 녹음 지금 지우기’를 누르면 바로 지우고, 서버를 다시 켤 때도 남은 것을 모두 지워요.
참고 녹음찾을 사람의 기준을 만드는 데
분석 결과(목소리 지문, 찾은 구간), 찾는 사람을 부르는 이름, ‘맞아요·아니에요’ 답결과를 보여 주고 내려받게 하는 데
접속 주소(IP)같은 곳에서 너무 자주 시작하지 못하게 막는 데서버 메모리에만 1시간 두고, 파일로 남기지 않아요.
이 브라우저에 저장한 작업 번호창을 닫았다 열어도 하던 결과로 돌아오는 데작업이 지워지면 쓸모가 없어지고, 다음에 들어올 때 지워요. 브라우저 설정에서 사이트 데이터를 지워도 돼요.

내려받은 파일(zip, 음성 파일)은 내려받은 기기에만 남아요.

하지 않는 것

  • 올린 녹음과 분석 결과를 모델 학습이나 다른 용도에 쓰지 않아요.
  • 다른 사람이나 회사에 주거나 팔지 않아요.
  • 누가 언제 무엇을 요청했는지 적는 접속 기록을 남기지 않아요.
  • 쿠키, 광고, 방문 분석 도구를 쓰지 않아요. 글꼴과 스크립트도 이 서버에서만 받아요.

거쳐 가는 곳

  • 연결은 Cloudflare를 거쳐 암호화돼요. Cloudflare는 전송을 맡으며, 접속 정보를 Cloudflare 자체 방침에 따라 처리할 수 있어요.
  • 분석은 운영자가 대한민국에서 운영하는 서버에서 해요. 한 번에 한 사람의 작업만 처리해요.

올리기 전에

  • 녹음에 나오는 사람들의 목소리도 개인정보예요. 본인이나 가족 녹음처럼 올려도 되는 녹음만 올려 주세요.
  • 결과는 자동 분석이라 다른 사람 목소리가 섞이거나 빠질 수 있어요. 들어 보고 확인하는 용도로만 쓰고, 본인 확인이나 증거 같은 용도로는 쓰지 마세요.
  • 기본 목소리 분석 모델이 비상업 조건이라 이 서비스도 비상업으로만 운영해요.
  • 한 번에 파일 30개, 녹음 길이 합쳐 30분까지 살펴봐요. 사용하는 사람이 많으면 차례를 기다릴 수 있어요.

지우기와 문의

결과 화면 위쪽의 ‘올린 녹음 지금 지우기’로 언제든 바로 지울 수 있어요. 처리방침이 바뀌면 이 페이지에 바뀐 날짜와 함께 적어요.
